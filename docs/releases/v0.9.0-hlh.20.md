## 存档页面修复（Android 重点）

- **下载新资源包后存档页显示 0 条**：服务端在请求的游戏版本没有分区存档时，
  现在会把未分区的 legacy 存档当作可继承来源（`load_kind=migrated`）。
  页面能正常列出 4 个存档键，历史与回滚也沿用实际分区。
- **普通账号也能回滚**：历史版本/下载/回滚不再要求 authentik Admins 组，
  只要存档属于当前账号即可；跨用户管理仍然只给管理员。
- **游戏内按钮改成「存档」**：所有登录用户都会看到右下角「存档」悬浮按钮，
  点击打开与 Web 端一致的存档管理面板（按游戏版本列出、历史、恢复、下载）；
  原来的独立「↑ 上传」按钮已移除。
- **自动上传只在游戏运行中发生**：由游戏页的同步脚本负责（约 3 秒防抖）；
  启动器只读取云端，不会上传本机数据。
- **21:9 短屏适配**：游戏内面板在高度 ≤ 430 px 时贴满屏幕、压缩标题栏，
  把空间留给存档列表。

## Windows

- 同步上述存档页面改动；启动与更新逻辑沿用 hlh.19 的修复。

## 已知边界

- 手机 21:9 下游戏画面本身仍由「画面比例」设置控制（均衡/完整/拉伸）。
