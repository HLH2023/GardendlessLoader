## 更新重点

- **游戏页面不再持有设备令牌**：启动器先向服务器换取 3 小时有效的「存档会话令牌」，
  页面只拿这一份；设备令牌留在原生/本地服务器侧。会话令牌只能读写存档、不能签发或吊销令牌，
  过期自动失效，吊销设备令牌会连带失效所有会话。
- **Windows 端有了完整的检查更新 → 下载 → 校验 → 自动替换**：替换由外部脚本执行，
  会先整目录备份，复制失败自动回滚，安装目录不可写时直接拒绝。
- **历史存档保留从 1000 降到 300**：按（用户 / 游戏版本 / 存档键）独立裁剪，
  永远删最旧的，跨版本互不影响。
- 安卓在线形态：心跳结果、令牌失效、前后台切换都有结构化日志；401 会退回启动器并在
  下次打开时清登录态。

## 修复

- 存档 API：未授权 POST 不再污染 keep-alive 连接（此前的偶发 `501 Unsupported method`）。
- 存档管理页：后台标签页停止 5 s 轮询；缺 device 字段的历史记录显示「历史设备（未记录）」。
- 资源包管理：迁移/切形态/导入补上持久化事务门禁，断电恢复窗口不再放行破坏性操作。
- `check_desktop_zip.dart` 的 fixture 说明修正（必须含 3 MiB `assets/big.bin`）。
- `tools/handoff.sh verify` 增加 `.ps1` 编码断言与 docs 敏感扫描。

## Windows 更新说明（重要）

- 更新包下载到资源根目录的 `downloads/`，校验通过后点「退出并自动更新」。
- 应用会退出，脚本等待进程结束后备份并覆盖安装目录，然后重新拉起；日志在系统临时目录
  `gardendless-update-*.log`。
- 安装在 `Program Files` 等受保护目录时，需要以管理员权限运行，否则会提示目录不可写。
