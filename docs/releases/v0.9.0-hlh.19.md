## 紧急修复：Windows 端无法启动

hlh.18 的 Windows 包双击后只有空白窗口，原因是启动时调用的原生日志通道
（`io.github.dey410.gardendlessloader/app_logger`）只在 Android / iOS / OHOS 有实现，
Windows 上直接抛 `MissingPluginException`，`runApp` 从未执行。现已改为：

- 日志初始化任何失败都降级到内存日志，**绝不再阻断启动**；
- 日志页仍可查看本次会话的事件（标记为「未持久化」）。

## 安全与健壮性

- **会话令牌失败时不再回退到设备令牌**：此前 `/token/session` 请求失败会把长期设备令牌
  注入游戏页，等于撤销了 hlh.18 的隔离；现在改为本次启动不启用云存档（离线照常玩）。
- **存储位置迁移拒绝「当前目录的上级目录」**：目标为父目录时，搬迁会先删除父目录里同名的
  `downloads` / `settings.json` 等内容，存在真实数据丢失风险。
- **Windows 更新脚本**：robocopy 路径显式加引号（修复安装在 `Program Files` 等带空格路径
  时备份必然失败）；回滚改用 `/MIR` 恢复精确状态；拒绝盘符根目录；失败路径清理临时目录；
  停止残留进程时按目录边界匹配。
- **服务端**：管理员接口的 `user` 参数拒绝 `../` 与绝对路径（防止 `/delete` 越界 rmtree）；
  `/version` 支持 `gameVersion`；空存档拦截的云端摘要读取正确版本；原子写补目录 fsync。
