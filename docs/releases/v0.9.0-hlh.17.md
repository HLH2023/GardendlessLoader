## 更新重点

- 安卓在线形态补齐可诊断性：心跳每次上报都写结构化日志，令牌失效（401/403）会停止心跳、
  自动退回启动器，并在下次打开启动器时清除登录态、提示重新登录。
- 破坏性操作门禁补齐持久化事务状态：崩溃/断电后遗留的导入事务未恢复时，
  迁移存储位置、切换游玩形态、导入资源都会被拒绝，不再可能搬走半成品资源槽。
- 资源包管理界面双端行为核对（Android / Windows 共用同一套文案与禁用判定）；
  明确本版本没有「多包列表/删除单个包」入口，导入即原子切换，旧槽自动清理。
- 新增安卓真机验收清单 `docs/acceptance-android.md`：点哪几步、看什么、失败抓哪段日志。

## 修复

- 存档 API：未授权 POST 不再污染 keep-alive 连接。此前 `do_POST` 先鉴权后读请求体，
  被拒请求的 JSON body 残留在连接里，会被 `http.server` 当成下一个请求行，
  表现为偶发 `501 Unsupported method ('{"id":...}GET')`（曾被误判为测试脚本问题）。
- 存档管理页：后台标签页不再每 5 秒轮询，切回时立即补一次刷新。
- 存档管理页：早期没有 `device` 字段的记录显示为「历史设备（未记录）」，不回填、不猜测。
- `check_desktop_zip.dart` 的 fixture 说明修正：必须含 3 MiB 的 `assets/big.bin`，
  旧文档写「任意 ZIP」会让套件以 PathNotFoundException 失败。
- `tools/handoff.sh verify` 新增 Windows 构建脚本编码断言（UTF-8 BOM + CRLF），
  防止 PowerShell 5.1 读中文注释直接语法报错。
