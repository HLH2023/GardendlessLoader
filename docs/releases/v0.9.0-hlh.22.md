## Windows 桌面宿主修复（重要）

- hlh.20/21 的 Windows 主界面在构建「游戏」页时会调用原生活宿主枚举，
  而该枚举只支持 android/iOS/OHOS，于是抛出
  `Unsupported operation: Gardendless native GameHost does not support windows`。
  现在 Windows/Linux/macOS 映射到 `dart-desktop`（本地 HTTP + webview_cef），
  界面与诊断不再报错，原生会话路径保持不变。

## 21:9 原生适配

- 「画面比例」默认改为「跟随屏幕」：WebView 使用手机真实比例，21:9 就是 21:9，
  不裁切、不加 16:9 黑边；保留「固定 17:9」与「强制拉伸」。
- 启动器短屏布局：侧边栏收窄并可滚动、开始页可整体滚动、存档页双栏
  （窄屏单列）都能完整滚到底部。
- 游戏内「存档」面板在高度 ≤540px 时全屏铺满，按钮触控目标 ≥40px。

## 测试

- 服务端 173 项、客户端 191 项（合计 364 项）全绿。
- Android JVM 视口单测 4 项通过；Windows 启动不再出现
  `Unsupported operation ... does not support windows`。
